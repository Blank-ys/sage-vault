# 确定通用企业文档问答 V1 产品基线

Type: grilling
Status: resolved
Blocked by: none

## Question

基于现有 RuoYi backend/frontend 二开时，V1 要为谁解决什么问题、包含哪些能力、以什么边界和指标判断内部试点成功？

## Answer

V1 定位为小范围真实使用的内部试点：知识管理员维护知识库和企业文档，普通用户在单一知识库内发起独立中文问答；系统覆盖异步入库、稠密检索、拒答、流式生成、历史和反馈，并以明确的质量、隔离、容量和性能门槛验收。

完整产品行为、89 条用户场景、实施决策、测试 seam、延期项和指标已综合进入 [通用企业文档问答 V1 规格](../spec.md)，本票不再保留副本。

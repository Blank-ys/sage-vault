# 03 — 回答公开制度问题并跳转条款原文

**What to build:** 员工能够用自然语言询问公开制度，获得只依据有权片段生成的答案及条款级引用，并从引用跳转到原 PDF 对应页。

**Blocked by:** 02 — 上传并生效一篇结构规整的公开制度文档

**Status:** ready-for-agent

- [ ] Java 根据当前登录用户组装授权声明并无条件追加 `PUBLIC`，一次调用 Python 即可获得完整问答结果。
- [ ] Python 通过 `VectorRetriever` 执行带标签求交过滤的 Milvus 向量 top-k 检索，并只把召回片段交给 `LLMClient` 生成答案。
- [ ] 问答响应包含答案以及可定位到制度文档、章/条和 PDF 页码的引用。
- [ ] 员工问答页面展示答案与引用，点击引用可打开原制度文档的对应页；Java HTTP 边界测试覆盖该完整行为。

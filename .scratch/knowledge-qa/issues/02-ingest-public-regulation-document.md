# 02 — 上传并生效一篇结构规整的公开制度文档

**What to build:** 制度管理员能够上传一篇 PDF 制度文档并将可见范围设为 `PUBLIC`；系统立即显示处理中，随后异步生成带条款、页码和可见范围信息的片段，完成后该制度文档进入可检索的生效状态。

**Blocked by:** 01 — 建立 Java–Python 安全服务契约

**Status:** ready-for-agent

- [ ] 管理端只接受 PDF，上传成功后保存制度文档及文件并立即返回 `ingestStatus=PROCESSING`。
- [ ] Python 按章/条结构切分文档，使用本地 bge-m3 生成 1024 维向量，并将带文档、条款、页码和 `PUBLIC` 标签的片段写入 Milvus。
- [ ] Python 成功回调后制度文档变为 `READY`；失败回调或异步任务触发失败时变为 `FAILED` 并保留可查看的失败原因。
- [ ] 管理员可在制度文档列表中查看入库状态，并能核验已生效文档的可见范围。

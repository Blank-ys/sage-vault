# 04 — 在依据不足时可靠拒答

**What to build:** 员工提出无法从其可见现行制度中找到可信依据的问题时，系统明确拒答并建议咨询 HR 或相关业务部门，不使用大模型通用知识猜测答案。

**Blocked by:** 03 — 回答公开制度问题并跳转条款原文

**Status:** ready-for-agent

- [ ] 向量检索结果未达到集中配置的可信阈值时，Python 返回结构化拒答而非生成普通答案。
- [ ] 拒答响应不包含虚构引用，使用约定的通用咨询提示，且 Java 接口与员工问答页面均能正确呈现。
- [ ] 测试证明无可信依据时不会将问题交给 `LLMClient` 依靠通用知识兜底。
- [ ] 可信度判据封装在可替换接缝后，未来可改用重排分数而不改变问答契约。

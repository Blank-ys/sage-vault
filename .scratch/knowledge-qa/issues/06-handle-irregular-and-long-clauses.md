# 06 — 处理非标准及超长制度条款

**What to build:** 系统能够可靠接纳结构无法解析或包含超长条款的 PDF：超长条款仍可完整检索并作为同一条款引用，非标准文档则降级为页级引用并提示管理员需要人工规整。

**Blocked by:** 02 — 上传并生效一篇结构规整的公开制度文档

**Status:** ready-for-agent

- [ ] 超过 bge-m3 输入上限的单条制度被拆为有重叠、共享同一条号的多个片段，条款后半段仍可被单独问题召回。
- [ ] 答案引用命中同一超长条款的多个片段时，面向员工合并显示为一个条款级引用。
- [ ] 结构解析失败的 PDF 自动降级为定长切分和页级引用，仍可进入 `READY`，并在管理端标记为待人工规整。
- [ ] 不可恢复的解析或嵌入错误使制度文档进入 `FAILED`，管理员能够看到失败原因。

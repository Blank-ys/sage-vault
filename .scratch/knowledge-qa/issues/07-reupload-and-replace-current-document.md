# 07 — 重新上传并原子替换现行制度

**What to build:** 制度管理员能够对同一制度文档重新上传 PDF，以新内容整体替换当前文件和全部片段；替换完成后的员工问答只依据最新生效内容，不会混合新旧矛盾条款。

**Blocked by:** 02 — 上传并生效一篇结构规整的公开制度文档；03 — 回答公开制度问题并跳转条款原文

**Status:** ready-for-agent

- [ ] 对同一 `documentId` 重新上传会覆盖当前文件并启动可观察的异步入库流程，而非创建可同时检索的新版本。
- [ ] 新内容成功生效后，Milvus 中该制度文档的旧片段被完整替换，问答及引用只反映新内容。
- [ ] 替换处理失败时制度文档显示 `FAILED` 及原因，不会让新旧片段同时成为可检索依据。
- [ ] 入库边界测试覆盖重新上传、状态流转、旧片段清除和无新旧混召行为。

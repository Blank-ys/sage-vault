# 07b — 单用户串行化生成与问答状态机、SSE 事件

**What to build:** 每个用户同一时间只能有一个正在生成的回答，第二次提问被拒绝并提示等待或停止当前回答，不同用户仍可并发；完成与拒答均持久化正确状态，SSE 至少覆盖 `started`、`delta`、`completed`、`refused`、`error`，拒答不计作成功回答。

**Blocked by:** 07a — 会话组织、永久历史与所有权级联删除.

**Status:** ready-for-agent

- [ ] Java 侧建立 per-user 并发闸门：同一用户同时只允许一个 in-flight 生成，第二次提问返回明确业务错误（提示等待或停止当前回答）。
- [ ] 不同用户的生成互不阻塞，可并发进行。
- [ ] 问答状态机建立 `completed`（完成）与 `refused`（拒答）终态并正确持久化。
- [ ] SSE 至少覆盖 `started`、`delta`、`completed`、`refused`、`error` 事件。
- [ ] 拒答不计作成功回答。
- [ ] 生成结束（完成、拒答或错误）后闸门可靠释放，避免死锁或误锁。
- [ ] 验证：受影响 Java 模块测试（含并发闸门用例）+ 系统验收覆盖同用户串行拒绝与跨用户并发。

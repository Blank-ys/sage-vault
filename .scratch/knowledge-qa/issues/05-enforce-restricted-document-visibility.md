# 05 — 让受限制度只对获授权员工可见

**What to build:** 制度管理员能够使用 RuoYi 现有角色和部门设置制度文档的可见范围；获授权员工可以基于该制度问答，无权员工的召回、生成上下文和响应中都不会出现该制度，其体验与制度不存在一致。

**Blocked by:** 03 — 回答公开制度问题并跳转条款原文

**Status:** ready-for-agent

- [ ] 管理员能为制度文档选择现有角色和部门作为可见范围，入库后的每个片段携带相应标签。
- [ ] Java 授权声明正确反映登录用户的角色、部门及 `PUBLIC` 标签，Python 在 Milvus 标量过滤中执行标签求交。
- [ ] 同一问题下，获授权员工获得受限制度的答案和引用，无权员工只能基于其他有权制度回答或拒答。
- [ ] 连接真实 Milvus 的安全不变式测试证明无权制度既不被召回、不进入 fake `LLMClient` 的上下文，也不出现在最终响应。

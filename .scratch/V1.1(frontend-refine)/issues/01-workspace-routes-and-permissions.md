# 01 — 建立问答与管理后台工作空间路由边界

**What to build:** 让登录后的用户默认进入问答工作台，并建立受现有动态菜单权限保护的管理后台入口。兼容根入口与 `/index` 进入问答工作台；管理概览使用 `/admin/index`；登录前访问有权限的管理深链接时，登录后恢复原目标；无管理权限访问管理后台时回到问答并提示无权限。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 普通登录、根入口和 `/index` 均进入问答工作台正式路径 `/sage/qa`
- [ ] `/admin/index` 仅对拥有至少一个后台动态菜单权限的用户开放
- [ ] “管理后台”入口仅对拥有后台权限的用户显示
- [ ] 无管理权限访问管理后台深链接时回到问答并显示一次无权限提示
- [ ] 登录前访问有权限的管理深链接时，登录后恢复原页面
- [ ] 不改变现有 Java API、菜单数据、权限标识和认证行为
- [ ] 通过真实浏览器验证四类权限组合的路由与入口结果

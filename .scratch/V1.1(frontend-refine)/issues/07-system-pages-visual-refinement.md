# 07 — 统一系统管理与系统监控页面换肤

**What to build:** 将系统管理、系统监控及其详情、日志、分配等子页面统一到新的管理后台视觉外壳。保留 RuoYi 原有信息架构、真实筛选字段、分页、按钮权限、弹窗和后端接口；筛选条件较少时可与操作区同排，条件较多时使用独立筛选行。

**Blocked by:** 05 — 统一后台视觉规范与验收边界.

- [x] 详情、授权、分配和编辑弹窗延续新的表单、按钮、间距和错误状态视觉

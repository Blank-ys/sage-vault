# 04 — 建立管理后台外壳与管理概览

**What to build:** 为获授权用户建立 `/admin/index` 管理概览和参考图风格的管理后台外壳。使用 Sage Vault / Management Console 品牌、深色侧栏、白色顶栏、面包屑和页面标题；顶栏提供授权菜单搜索、返回问答、消息通知和头像菜单；管理概览展示按现有动态菜单权限生成的管理功能导航，不展示若依宣传或伪造统计。

**Blocked by:** 01 — 建立问答与管理后台工作空间路由边界.

**Status:** ready-for-agent

- [ ] `/admin/index` 展示 Sage Vault 管理概览而非若依宣传内容
- [ ] 概览按动态菜单权限和顺序显示管理功能导航
- [ ] 不展示无权入口、统计卡片、虚构数据、参考站品牌或 GitHub Star
- [ ] 管理后台使用深色侧栏、白色顶栏、面包屑和页面标题
- [ ] 侧栏保留后端动态菜单层级、顺序、图标和权限事实
- [ ] 顶栏提供管理菜单搜索、返回问答、通知和右上角头像菜单
- [ ] 不显示可见 TagsView，使用侧栏、面包屑和标题导航
- [ ] 返回问答优先恢复离开前的问答会话，无恢复位置时进入新对话
- [ ] 不改变动态菜单 API、权限标识和后台业务接口

# 02 — 重塑问答工作台桌面布局与会话导航

**What to build:** 将知识问答呈现为独立全屏工作台：左侧提供 Sage Vault 品牌、新建会话、标题搜索、会话列表和管理后台入口，右侧提供问答主区域。保留现有会话加载、选择、重命名、删除和知识库绑定行为；新会话在主区域选择知识库，已有会话只读显示知识库名称。

**Blocked by:** 01 — 建立问答与管理后台工作空间路由边界.

**Status:** ready-for-agent

- [ ] 问答工作台不显示后台侧栏、顶栏、面包屑或可见多页签条
- [ ] 左侧包含品牌区、新建会话、按标题过滤的搜索框、会话列表和管理后台入口
- [ ] 管理后台入口按权限显示并位于新建会话区域
- [ ] 新会话在主区域选择知识库，未选知识库前不可提问
- [ ] 已有会话顶部显示会话标题和只读知识库名称
- [ ] 长知识库名称可截断且可查看完整名称；已删除知识库显示已删除并禁止继续提问
- [ ] 会话搜索只过滤当前加载的会话标题，不读取或持久化问题/回答正文
- [ ] 重命名和删除收敛到省略号菜单，删除继续二次确认
- [ ] 保留现有会话 API、知识库绑定、历史读取和删除语义
